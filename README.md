# Python Practice

A structured repository documenting my journey of learning Python, strengthening programming fundamentals, solving problems, and developing practical coding skills.

This repository serves as a record of my progress, from basic syntax to advanced concepts, problem-solving exercises, and small projects.

## About This Repository

The purpose of this repository is to build a strong understanding of Python through consistent practice and hands-on implementation.

Rather than focusing only on theory, I aim to write code regularly, understand how different concepts work, solve problems independently, and apply what I learn to practical situations.

## Learning Roadmap

### 1. Python Fundamentals

- Variables and data types
- Keywords and identifiers
- Operators and expressions
- Type conversion
- User input and output
- Conditional statements (`if`, `elif`, `else`)
- Loops (`for` and `while`)
- Nested loops
- Pattern-printing problems
- Basic mathematical programs

**Goal:** Develop a clear understanding of Python syntax and control flow.

### 2. Data Structures

- Strings and string manipulation
- Lists and list operations
- Tuples
- Sets and set operations
- Dictionaries and key-value pairs
- Indexing and slicing
- Nested data structures
- List, dictionary, and set comprehensions
- Iteration and membership testing

**Goal:** Understand how to store, access, modify, and process collections of data efficiently.

### 3. Functions and Modular Programming

- Defining and calling functions
- Parameters and return values
- Positional and keyword arguments
- Default arguments
- Variable-length arguments (`*args` and `**kwargs`)
- Scope of variables
- Lambda functions
- Recursive functions
- Built-in functions
- Modules and packages
- Importing modules

**Goal:** Write reusable, readable, and well-organised programs.

### 4. Problem-Solving and Algorithms

- Number-based problems
- String manipulation problems
- Array and list problems
- Searching techniques
- Sorting techniques
- Frequency counting
- Two-pointer techniques
- Basic recursion
- Mathematical problem-solving
- Time and space complexity
- Introduction to Big-O notation

**Goal:** Improve logical thinking and learn to solve programming problems systematically.

### 5. Object-Oriented Programming

- Classes and objects
- Constructors and the `__init__()` method
- Instance and class attributes
- Instance, class, and static methods
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Method overriding
- Special methods
- Composition

**Goal:** Understand how to organise code using object-oriented principles.

### 6. File Handling and Data Processing

- Reading and writing text files
- Working with file paths
- Context managers and the `with` statement
- CSV file processing
- JSON data handling
- Exception handling
- Custom exceptions
- Processing structured data
- Basic data validation

**Goal:** Learn how Python programs interact with files and handle real-world data.

### 7. Advanced Python Concepts

- Iterators and iterables
- Generators and `yield`
- Decorators
- List and generator expressions
- Context managers
- Type hints
- Docstrings
- Regular expressions
- Working with dates and times
- Virtual environments
- Package installation with `pip`
- Dependency management

**Goal:** Develop familiarity with Python features that support maintainable and efficient applications.

### 8. Libraries and Data Analysis

I will gradually explore Python's data-processing and visualisation ecosystem.

#### NumPy
- Array creation and manipulation
- Indexing and slicing
- Array broadcasting
- Vectorised operations
- Mathematical operations
- Aggregation functions
- Basic linear algebra

#### Pandas
- Series and DataFrames
- Reading CSV files
- Inspecting datasets
- Filtering and sorting
- Handling missing values
- Removing duplicates
- Grouping and aggregation
- Merging and joining datasets
- Data type conversion
- Data cleaning

#### Matplotlib
- Line plots
- Bar charts
- Histograms
- Scatter plots
- Plot customisation
- Titles, labels, legends, and axes
- Comparing distributions
- Visualising relationships between variables

#### Additional Libraries
- Seaborn for statistical visualisation
- SciPy for scientific computing
- Scikit-learn for exploring machine-learning concepts when my foundations are ready

**Goal:** Learn how Python can be used to process, analyse, and visualise data.

### 9. Testing, Debugging, and Code Quality

- Understanding error messages
- Debugging programs
- Assertions
- Unit testing with `pytest`
- Writing test cases
- Handling edge cases
- Code readability
- PEP 8 style conventions
- Basic logging
- Type annotations
- Writing meaningful comments and docstrings

**Goal:** Develop the habit of writing code that is understandable, testable, and reliable.
